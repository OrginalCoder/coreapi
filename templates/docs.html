CoreAPI Hujjatlari

CoreAPI — sun’iy intellekt (AI) modellariga savol yuborish va JSON formatida javob olish imkonini beruvchi yengil, ochiq va zamonaviy REST API platformasi.

Ushbu API orqali siz o‘zingizning Telegram botlaringiz, veb-sahifalaringiz, Python skriptlaringiz yoki mobil ilovalaringizga AI imkoniyatlarini bir necha qator kod bilan ulay olasiz.

Hech qanday ro‘yxatdan o‘tish yoki tashrif buyuruvchi kaliti talab qilinmaydi. API barcha ishlab chiquvchilar uchun ochiq. So‘rov yuborish uchun faqat savol matnini JSON formatida jo‘natish kifoya.

5. Xatolik javoblari

Barcha xatoliklar standart va tushunarli tuzilmada qaytariladi. Hech qanday ichki traceback yoki yashirin ma’lumotlar oshkor etilmaydi:

1. So‘rov formati noto‘g‘ri (HTTP 400 Bad Request)

{
  "success": false,
  "error": {
    "code": "invalid_request",
    "message": "So‘rov formati noto‘g‘ri."
  }
}

2. Savol kiritilmagan (HTTP 400 Bad Request)

{
  "success": false,
  "error": {
    "code": "missing_question",
    "message": "Savol maydoni kiritilishi kerak."
  }
}

3. AI provayderi mavjud emas (HTTP 503 Service Unavailable)

{
  "success": false,
  "error": {
    "code": "provider_unavailable",
    "message": "AI xizmati hozircha javob bermayapti."
  }
}

4. AI provayderi javob berish vaqti tugadi (HTTP 504 Gateway Timeout)

{
  "success": false,
  "error": {
    "code": "provider_timeout",
    "message": "AI xizmatidan javob kutish vaqti tugadi."
  }
}

5. Juda ko‘p so‘rov yuborildi (HTTP 429 Too Many Requests)

{
  "success": false,
  "error": {
    "code": "rate_limit_exceeded",
    "message": "Juda ko‘p so‘rov yuborildi. Iltimos, 30 soniyadan so‘ng qayta urinib ko‘ring."
  }
}

6. So‘rov hajmi me’yordan katta (HTTP 400 Bad Request)

{
  "success": false,
  "error": {
    "code": "payload_too_large",
    "message": "So‘rov hajmi 256 KB dan oshmasligi kerak."
  }
}

6. Integratsiya namunalari

Istalgan dasturlash tilida quyidagi namunalardan foydalanib APIni integratsiya qilishingiz mumkin:

Python (requests)

python 
import requests

url = "https://coreapi.pythonanywhere.com/api/v1/chat/"

response = requests.post(
    url,
    json={"question": "Python nima?"},
    timeout=60,
)

print(response.status_code)
print(response.json())

JavaScript (Fetch API)

javascript 
const response = await fetch("https://coreapi.pythonanywhere.com/api/v1/chat/", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    question: "JavaScript nima?"
  })
});

const data = await response.json();
console.log(data);

cURL (Terminal)

bash 
curl -X POST https://coreapi.pythonanywhere.com/api/v1/chat/ \
  -H "Content-Type: application/json" \
  -d '{"question": "Python nima?"}'
